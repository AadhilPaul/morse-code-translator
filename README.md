# 📡 Morse Code Translator

A simple **Morse code translator built with HTML, CSS, and vanilla JavaScript**.

The project provides a browser-based interface for converting text into Morse code and translating Morse code back into readable text.

## ✨ Features

* Convert text to Morse code
* Convert Morse code back to text
* Simple browser-based interface
* No frameworks or external libraries required
* Instant client-side translation

## 🛠️ Tech Stack

* **HTML5** — Page structure
* **CSS3** — Styling and layout
* **JavaScript** — Translation logic and user interaction

## 🧠 How It Works

The application uses JavaScript to map characters to their corresponding Morse code representations.

For example:

```text
HELLO
```

becomes:

```text
.... . .-.. .-.. ---
```

The reverse mapping allows Morse code to be translated back into regular text.

All translation happens directly in the browser using client-side JavaScript.
